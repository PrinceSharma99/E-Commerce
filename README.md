# Ladies Smart Choice - Premium Fashion Store

Ladies Smart Choice is a modern, responsive e-commerce web application designed for a premium fashion shopping experience. It features a curated collection of high-quality fabrics and garments including Premium Woolen, Velvet, Russian Crape, Paper Silk, and Banarasi Silk.

## ✨ Features

- **Product Diversity**: Extensive collection across multiple categories like Premium Woolen, Velvet, Silk, and more.
- **Dynamic Filtering**: Easily filter products by category or use the search bar to find specific items.
- **Shopping Cart**: Fully functional cart system where users can add items, adjust quantities, and see real-time price updates.
- **Wishlist**: Save your favorite items for later with a personalized wishlist.
- **Premium UI/UX**: Features a clean, luxury aesthetic with smooth animations, notification systems, and responsive layouts.
- **Newsletter Subscription**: Integrated newsletter signup for exclusive offers.
- **Currency & Language Support**: Support for INR/USD and English/Hindi (placeholders).

## 🛠️ Technologies Used

- **HTML5**: Semantic structure for better SEO and accessibility.
- **CSS3**: Custom styling with a focus on modern, responsive design and premium aesthetics.
- **JavaScript (Vanilla)**: Core logic for product rendering, cart management, wishlist, and search functionality.
- **Font Awesome**: iconography for a professional look.
- **Google Fonts**: Modern typography for enhanced readability.

## 🚀 Getting Started

### Prerequisites
A modern web browser (Chrome, Firefox, Edge, Safari).

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/e-commerce.git
   ```
2. Navigate to the project directory:
   ```bash
   cd e-commerce
   ```
3. Open `index.html` in your browser.
